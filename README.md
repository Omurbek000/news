## 🎯 О проекте

Проект создан в учебных целях – для практики разработки полноценного веб-приложения с авторизацией, постами, комментариями, избранным и личными сообщениями.  
Фронтенд – **React + Vite**, бекенд – **Django REST Framework**. Дизайн – яркий неоновый (оранжево-розовые акценты на тёмном градиенте).

**Пользователь может:**
- Зарегистрироваться / войти
- Смотреть ленту постов (пагинация, поиск, фильтр по категориям, сортировка)
- Читать пост целиком, ставить лайк/избранное, комментировать
- Писать новые посты с картинками (только авторизованные)
- Редактировать свой профиль (аватар, имя, телефон, bio)
- Добавлять посты в избранное и просматривать список избранного
- Отправлять и получать личные сообщения (с отображением непрочитанных)

## ⏳ Что ещё не готово / требует доработки

| Задача | Статус | Приоритет |
|--------|--------|------------|
| Редактирование/удаление своих постов | ❌ Не реализовано | Высокий |
| Редактирование/удаление комментариев | ❌ Не реализовано | Средний |
| Пагинация в избранном и сообщениях | ❌ Только на главной | Низкий |
| Возможность ставить оценку постам (звёзды/лайки) | ❌ Нет | Низкий |
| Уведомления о новых сообщениях (WebSocket) | ❌ Нет | Средний |
| Загрузка аватара через форму профиля (с предпросмотром) | ⚠️ Частично (работает, но без обновления навбара сразу) | Средний |
| Индикатор загрузки при отправке форм | ⚠️ Есть в некоторых местах | Низкий |
| Полноценное тестирование (unit/e2e) | ❌ Отсутствует | Низкий |
| Документация API (Swagger) | ⚠️ Установлена, но не настроена | Низкий |
| Развёртывание на сервере (Docker / VPS) | ❌ Не делалось | Низкий |

> **Примечание:** Проект учебный, поэтому многие «высокоприоритетные» задачи отложены ради изучения базовых механик.
